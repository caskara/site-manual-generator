# 网站操作手册生成器

根据网站名称或网址，自动爬取网站内容，使用 AI 分析并生成结构化的 DOCX 操作手册，含自动配图、弹窗清除、登录模式等特性。

## 何时调用

- 用户提供了一个网站的名称或 URL，并要求生成操作手册 / 使用指南 / 用户手册 / 操作教程
- 用户说"帮我写一下这个网站怎么用"、"生成一份 XX 网站的操作手册"等类似请求
- 需要为某个 Web 应用整理使用说明文档
- 用户提到"site-manual-generator"或"smg"

## 核心特性

- 🌐 智能爬取：基于 Playwright，支持 JS 渲染页面，自动提取导航链接
- 🤖 AI 分析：自动生成三级结构大纲（1 / 1.1 / 1.1.1）
- 📄 精美 DOCX：封面、目录、表格、规范排版
- 🖼️ 自动配图：每个章节匹配最合适的页面截图
- 🚫 自动清弹窗：Cookie、广告、登录提示等自动清除
- 🔐 手动登录模式：需要登录的网站，手动登录后带着登录态爬取

## 使用方式

本技能通过两种方式生成手册：

### 方式一：使用 MCP Server（推荐）

通过 MCP 协议调用 `site-manual-generator` MCP Server，使用以下工具：

1. **`generate_manual`** — 一键生成完整操作手册
   - 输入：`url`（必填）、`language`、`focus_areas`、`output_filename`、`max_pages`、`max_depth`、`login_mode`
   - 输出：DOCX 文件路径

2. **`crawl_site_only`** — 仅爬取网站，查看结构
   - 输入：`url`、`max_pages`
   - 输出：网站结构 JSON

3. **`generate_outline`** — 仅生成手册大纲
   - 输入：`url`、`language`、`focus_areas`
   - 输出：大纲 JSON

### 方式二：命令行调用

当 MCP Server 不可用时，直接运行 CLI：

```bash
smg generate <url> [options]
```

常用参数：
- `-o` 指定输出文件
- `--max-pages` 最大爬取页数
- `--login` 启用手动登录模式
- `--show-browser` 显示浏览器（调试用）
- `-i` 交互式模式

## 工作流程

1. **确认需求**：明确目标网站 URL、手册范围、输出语言
2. **选择模式**：
   - 公开网站 → 直接爬取
   - 需要登录 → 启用 `--login` 模式
3. **爬取+分析**：自动爬取页面、清弹窗、截图，AI 生成大纲和内容
4. **生成手册**：输出 DOCX 文件（含目录、章节、截图）
5. **交付结果**：告知文件路径，确认是否需要调整

## 注意事项

- 遵守目标网站的 robots.txt 和服务条款
- 登录模式下浏览器上下文仅本次运行有效，不存盘
- AI 生成内容可能有误差，建议人工校对
- 国内用户推荐使用 DeepSeek 等国内 LLM
