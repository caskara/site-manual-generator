# 手册结构模板

生成操作手册时参考的标准结构。

## 标准结构

```
1. 概述
   1.1 产品简介
   1.2 核心功能
   1.3 适用人群
   1.4 访问方式与环境要求

2. 快速入门
   2.1 账号注册与登录
   2.2 界面总览
   2.3 首次使用三步曲

3. 功能详解
   3.x 模块名称
       - 功能说明
       - 操作步骤
       - 界面说明
       - 注意事项

4. 常见问题（FAQ）

5. 进阶技巧 / 最佳实践

6. 帮助与支持
```

## 写作规范

- 步骤类内容用编号列表，每步一个动作
- 按钮、菜单名称用【】标注
- 重要提示用 ⚠️，小技巧用 💡
- 语言清晰简洁，适合目标读者
